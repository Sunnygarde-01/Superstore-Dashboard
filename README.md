# Superstore-Dashboard
🔷 Project Title 
Superstore Sales Analytics Dashboard (Power BI)

🔷 Short Description / Purpose
This is an interactive data visualization dashboard built using Power BI Desktop to analyze Superstore sales data.
The dashboard provides insights into sales performance, customer behavior, product trends, and regional analysis to support data-driven decision-making.

🔷 Tech Stack
The dashboard was developed using the following tools and technologies:
• Power BI Desktop – For building interactive reports and dashboards
• Power Query – For data cleaning and transformation
• DAX – For calculated measures and KPIs
• Data Modeling – Creating relationships between tables for accurate analysis
• File Format – .pbix for development and .png for preview

🔷 Data Source
Dataset: Superstore Sales Dataset
Contains information such as:
• Orders
• Sales & Profit
• Customers
• Product Categories & Sub-Categories
• Regions and Segments

🔷 Dashboard Structure (Pages)
The report is divided into multiple pages for better analysis:
1) Main Report
 • Overall KPIs (Sales, Profit, Orders, Quantity)
 • High-level business overview

2) Regional Analysis
 • Region-wise sales performance
 • Map visualization for geographical insights

3) Category Analysis
 • Sales & profit by product category and sub-category
 • Identification of top-performing categories

4) Customer Analysis
 • Customer segments analysis (Consumer, Corporate, Home Office)
 • Buying behavior insights
5) Sales Performance Analysis
 • Monthly and yearly trends
 • Growth patterns
6) Product Details
 • Detailed product-level performance
7) Tooltip Pages
 • Enhanced user experience with drill-through insights

🔷 Features / Highlights
• Interactive filters (Region, Category, Segment, Year)
• KPI Cards (Total Sales, Profit, Orders, Profit Margin, Avg Order Value)
• Drill-down and drill-through functionality
• Dynamic visuals using DAX measures
• Clean and structured UI design
• Tooltips for detailed insights

🔷 Business Problem
Businesses often struggle to track performance across regions, categories, and customer segments in a single view.
This dashboard solves that problem by providing a centralized and interactive platform for analysis.

🔷 Key Insights
Identify top-performing regions and categories
Understand customer segment contribution
Track sales trends over time
Analyze profit margins and order patterns
